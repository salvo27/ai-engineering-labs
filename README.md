# ai-engineering-labs

Welcome to my AI Transition Manual! This self-paced repo tracks my journey from Software Engineer to AI Engineer. Built 100% self-taught on top-tier, open-access curriculums (starting with the MIT deep learning materials), it is architected as a step-by-step blueprint for any software engineer looking to replicate my path. Feel free to use it as your own guide!

Everything here is written in my own words, with my own examples and analogies, in two languages: **English** and **Italian** (`-en` / `-it` files and `en/` / `it/` folders).
